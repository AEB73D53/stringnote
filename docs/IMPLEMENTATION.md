# 第一版实现说明

日期：2026-10-21。

## 已实现

- 响应式发现页、本机谱库、16 个常用和弦指法、练习工作台。
- iTunes 公开歌曲版本查询、可指定歌名/歌手的站外曲谱搜索入口。
- 原创《晚风练习曲》与经典旋律《小星星》《欢乐颂》的自行编配；真实拨弦合成 WAV。
- 本机 MP3/WAV 解码、独立 Worker 进行真实频谱和弦分析、取消与失败处理。
- 和弦与时间位置修改、拆分合并、撤销、恢复初始谱。
- 变调夹指法、谱面移调、基础指法推荐；明确区分谱面和原音频的音高。
- 真实音频播放、变速、进度跳转、音量、A–B 循环、跟随播放的参考节拍器。
- IndexedDB 保存谱面与音频；导出 JSON、ChordPro、音频，浏览器打印；图片谱导入与缩放。
- GitHub Actions 测试/构建/Pages 发布配置；哈希页面切换与项目基础路径。

## 相对计划的实现选择

采用 React + TypeScript + Vite，取代候选 Next.js 静态导出。当前交互全部在浏览器运行，无需服务器渲染，使用 Vite 更直接。

和弦谱采用自有时间片段结构与 React 排版，首版没有引入 ChordSheetJS。导出使用兼容 ChordPro 的文本格式，并用标准 comment 扩展保留精确时间。后续歌词排版或完整六线谱可在统一数据结构上加入专门渲染库。

音频识别采用可运行的频谱/chroma/模板匹配/Viterbi 基线。没有把它宣称为神经模型，也没有替代真实录音质量验证。接入更复杂模型前，应使用真实、有使用权限的流行歌录音与人工标注比较识别质量、修改成本和手机性能。

## 当前边界

站外找谱是搜索入口，尚未实现直接在站内聚合、读取并验证第三方曲谱全文。用户需要在原站确认版本，再导入自有谱；站内没有伪造流行歌曲的和弦谱。

自动识别输出基础大/小和弦草稿，不能可靠还原七和弦、复杂转位、旋律、原曲右手节奏或完整六线谱。节拍器采用参考 BPM 从音频 0 秒计拍，并不保证已识别原曲的第一拍。

本机收藏不是云端账户。清除浏览器数据、换设备或更换部署地址可能无法取得原本记录。导出数据和音频可用于备份。
