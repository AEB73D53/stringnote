## 浏览器验收清单

- [ ] 首页和练习入口可用，控制台无未处理错误。
- [ ] 内置练习曲的标题、来源、和弦与合成音频匹配。
- [ ] 搜索区分站内练习曲与站外查谱；无结果有可用下一步。
- [ ] 外链包含用户输入的歌名/歌手，并在新窗口安全打开。

- [ ] 播放、暂停、跳转和循环后高亮与已存时间轴保持同步。
- [ ] 导出能保存实际修改，重新导入后保留必要字段。

- [ ] 390px 手机视口无横向溢出，主要控件可操作。
- [ ] 键盘焦点可见，对话框可关闭，主要图标按钮有名称。
